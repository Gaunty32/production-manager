name: Knowledge Centre Facebook sharing
description: User requirements for daily sharing of new Knowledge Centre articles to their Facebook page.
---

Check the Knowledge Centre daily for new articles and publish new articles to the company's Facebook page.

**Why:** The user explicitly requested this recurring workflow.

**How to apply:** Each post must include the article image, its first paragraph, and a Read more link directly to that article on the company's Knowledge Centre, not the external source feed. Avoid duplicate posts. Do not describe the automation as active until the page is connected and scheduling is actually enabled.

Keep the integration on Facebook rather than switching to HighLevel.

**Why:** After being offered a HighLevel alternative, the user said, “lets fix the facebook connection.”

**How to apply:** Continue with a Facebook connection unless the user chooses another approach. Do not silently substitute a different publishing provider.

The intended Facebook destination is https://www.facebook.com/profile.php?id=61589820736319. Do not publish these articles to Select Uniforms.

**Why:** The user explicitly rejected Select Uniforms when it appeared during token validation and supplied this destination instead.

**How to apply:** Verify the authorised Page matches the supplied destination before enabling or testing publication. Access to a different Page is not permission to substitute it.
