---
name: DPD shipping quote policy
description: Business constraints for quoting larger shipments and selecting delivery services.
---

The user has fixed customer box charges up to four boxes. Above four boxes, they currently wait for the weekly DPD invoice to determine carriage, which delays customer invoicing.

**Why:** The user described this as an invoicing problem and supplied their quotation and recent invoices for analysis.

**How to apply:** Keep estimated DPD cost separate from the customer selling price. The user chose estimated cost plus a **20% markup**, before VAT, for shipments above four boxes. Preserve the existing up-to-four-box tariff. Estimates must not be presented as confirmed DPD invoice amounts.

The user is happy to use the cheapest delivery service.

**Why:** The user explicitly stated this when asking about postcode zones and surcharges.

**How to apply:** Compare eligible services for the actual destination, weight and parcel type, making delivery-speed differences visible. Do not assume a generic postcode-zone image overrides the account quotation.
