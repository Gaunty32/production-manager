---
name: Customer print artwork
description: Customer responsibility for print-only artwork, distinct from embroidery preparation.
---

For print-only portal orders, the customer supplies print-ready files set to the correct colour and size. Digitising, embroidery files and Madeira thread colours are not required.

**Why:** The user explicitly distinguished print artwork preparation from embroidery setup requirements.

**How to apply:** Keep print-only submission requirements separate from jobs containing embroidery; do not introduce embroidery setup requirements or charges into the print-only customer flow.
